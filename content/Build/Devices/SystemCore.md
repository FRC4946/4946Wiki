SystemCore is a new robot control system for [[FIRST Robotics Competition]] and FIRST Tech Challenge robots, which is scheduled to be released in 2027.

![[systemcore-1.jpeg]]
# SystemCore Hardware Specifications
- RAM: 4GB
- Storage: 16GM
- Onboard GPU for vision processing
- Digital I/O Ports: 6
- USB-A Ports: 4
- CAN loops: 5
- Ethernet for connectivity
- USB C for writing software
