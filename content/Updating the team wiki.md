# Tools needed to update
- [GitHub Desktop](https://desktop.github.com/download/)
- [Obsidian](https://obsidian.md/)

# Update procedure
1. Download the GitHub repository using GitHub Desktop
2. Make a branch for your updates
3. Open your branch as a vault in Obsidian
4. Create or update the files you intend to update
5. Confirm with Tanner before merging your branch in the v4 main branch
